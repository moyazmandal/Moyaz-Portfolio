# 🚀 Moyaz Mandal Portfolio

A modern and responsive personal portfolio website built to showcase my skills, projects, experience, and achievements as a Front-End Web Developer.

## 🌐 Live Demo

https://moyazmandal.vercel.app/

## 📌 About The Project

This portfolio website highlights my professional journey, technical skills, featured projects, volunteer activities, and contact information. The website is designed with a clean user interface, smooth animations, and responsive layouts to ensure an excellent experience across all devices.
